# Parlomi: preliminary name screening

Checked 22 September 2026 (Australia/Sydney). Research only: no purchases,
registrations, messages to owners, or project renaming performed.

## Assessment

No exact-name app or trademark result was found in the searches below. However,
the .com and several exact social handles are registered, and similar names are
used for communication and language products. Parlomi remains a candidate, not a
cleared name. A trade mark attorney should assess similarity and rights in the
intended launch countries before a commercial commitment. This is not a complete
clearance search or an infringement opinion.

- Australian quick searches `Parlami`, `Parlomo`, and `Parloma` also returned 0.

- USPTO: Wordmark search `Parlomi`, live and dead statuses selected, returned
  "No results found". https://tmsearch.uspto.gov/
- WIPO Global Brand Database: embedded brand-name search `Parlomi` returned
  "No results found". https://branddb.wipo.int/
- WIPO fuzzy search `Parlomi` returned 1,976 results. Only the initial visible
  entries were inspected; this broad result set was NOT comprehensively reviewed

No dedicated EUIPO or UKIPO search was completed. WIPO coverage is not universal.
Sound-alike, logo, unregistered-rights and goods/services assessment remain open.
